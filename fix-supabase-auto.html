🔧 Auto Fix Supabase RLS Recursion

⚠️ Lưu ý: Script này không thể tự động chạy SQL trên Supabase vì cần quyền admin. Vui lòng làm theo hướng dẫn bên dưới.
1 Mở Supabase Dashboard

Vào: Supabase Dashboard

2 Vào SQL Editor

Click vào "SQL Editor" ở menu bên trái

3 Copy SQL bên dưới

Click nút "Copy SQL" để copy code

4 Paste và Run

Paste vào SQL Editor và click "Run" (hoặc Ctrl+Enter)

SQL Code để Fix:

-- Drop old policy có vấn đề
DROP POLICY IF EXISTS "PT can manage users" ON users;

-- Drop policy mới nếu đã tồn tại (tránh lỗi duplicate)
DROP POLICY IF EXISTS "Allow all users manage" ON users;

-- Tạo policy mới không có recursion
CREATE POLICY "Allow all users manage" ON users FOR ALL USING (true);

-- Kiểm tra kết quả
SELECT schemaname, tablename, policyname 
FROM pg_policies 
WHERE tablename = 'users';
