# PWA Icons

Cần tạo 2 icon files:
- `icon-192x192.png` - 192x192 pixels
- `icon-512x512.png` - 512x512 pixels

Có thể sử dụng favicon.ico hiện tại làm base và resize thành các kích thước này.

Hoặc tạo icon mới với:
- Background: #2563eb (blue)
- Icon: Dumbbell hoặc PT logo
- Format: PNG với transparency
